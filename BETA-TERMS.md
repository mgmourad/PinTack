# PinTack beta — notes for testers

Thank you for trying PinTack. Short version: it is not finished, so keep a backup.

**It carries no warranty.** PinTack is free software under the GNU General Public License, version 3
or later — the full text is in `LICENSE`, and the About pane links the licences of everything it is
built on. This beta is provided as-is, with no guarantee that it works, that it keeps working, or
that it is fit for any particular purpose. The developer is not liable for any loss arising from
using it.

**Your notes are plain files, and they are yours.** PinTack keeps everything in Markdown files in a
folder you choose. Nothing is uploaded: the app makes no network connection at all except link
previews, which are off unless you turn them on. If you stop using PinTack your notes stay where they
are, readable in any text editor.

**Please keep a backup anyway.** It is a beta. Point it at a folder you can afford to lose, or copy
your vault somewhere safe before each new build.

**Feedback is the point.** Bugs, confusions, things that feel wrong, things you wanted and could not
find — all of it is welcome, and specific is better than polite. If a note behaves oddly, the note's
raw Markdown is usually more useful than a screenshot.

**Crash reports and diagnostics.** Nothing is collected automatically. If something breaks, tell the
developer what happened, or open an issue at https://github.com/mgmourad/PinTack.
